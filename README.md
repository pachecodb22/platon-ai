# 🏛️ Platón AI - Auditoría y Redacción Académica con LLMs

**Platón AI** es un asistente web especializado en el análisis del discurso, la auditoría lógica de argumentos y la reformulación de textos académicos. Desarrollada por **Daeni José Pacheco Berroterán** como proyecto de evaluación final para la **Microcredencial Universitaria en Inteligencia Artificial Generativa para Todos** de la **Universidad Carlos III de Madrid (UC3M)**.

---

## 📋 Descripción de la Aplicación

Platón AI utiliza modelos de lenguaje a través de la API de Groq para ofrecer cuatro funciones principales:

1. **📋 Resumen Ejecutivo:** Síntesis panorámica con extracción de puntos fuertes, aspectos a mejorar y conceptos clave.
2. **✍️ Análisis de Redacción:** Evaluación sintáctica, detección de ambigüedades, muletillas y verificación del nivel de registro académico.
3. **⚖️ Auditoría Argumentativa:** Detección automática de tesis centrales, falacias lógicas, premisas no justificadas y saltos inferenciales.
4. **🔄 Reformulador Académico:** Reescritura orgánica de borradores para elevar el rigor formal y corregir fallas argumentativas.
